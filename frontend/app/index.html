      how it works

      One address, one proof, one key

      A payer sees the locked ZEC, sends the Venmo, and proves it through the same enclave zk-p2p uses. That proof is the only thing that can release the escrow. If nobody pays within a day, your own key alone takes the coins back.

      01

      Type their handle, get an address

      Enter their Venmo username and an amount. Your key is made in this page and never sent anywhere. The address it derives is an escrow whose refund branch only that key can spend, and the page checks that before it shows you anything.

      @handle→your key→t3 address
      02

      Send ZEC from any wallet

      One transaction, exactly the amount shown. Once it confirms, this page signs the release under one condition: a proof that the dollars reached the handle you typed. Nothing leaves Zcash until then.

      ZEC→escrow locks→waiting for a payer
      03

      Released on the proof, or refunded by you

      A payer sends the Venmo and asks the enclave to attest it. That attestation completes the release and the payer collects the ZEC. If nobody pays within a day, your key alone signs the refund; no one has to approve it.

      Venmo→enclave attestation→release
